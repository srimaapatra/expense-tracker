# 💰 Expense Tracker

A simple and modern Expense Tracker web application built using HTML, CSS, and JavaScript.

Users can:
- Add income and expense transactions
- View total balance
- Track income and expenses separately
- Delete transactions
- Store data using LocalStorage

---

✅ Add Transactions  
✅ Delete Transactions

## 📌 How It Works

### ➜ Add Transaction
Users enter:
- Transaction text
- Amount

Positive amount → Income  
Negative amount → Expense

---

### ➜ Balance Calculation

The app calculates:
- Total Balance
- Total Income
- Total Expense

using JavaScript array methods:
- `map()`
- `filter()`
- `reduce()`

---

### ➜ LocalStorage

Transactions are saved in browser LocalStorage, so data remains even after refreshing the page.
